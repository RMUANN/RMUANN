# 网站设计规范

## 阅读路径

首页先呈现姓名、学术与工程定位，再以交互式人体示意说明动作调节。接下来依次展示研究案例、工程案例、论文、简介、经历和联系方式。研究与工程采用同一栅格，论文和经历采用可快速扫读的列表。项目详情由叙述正文、概念图和相关出版物组成。

## 视觉与界面

| 用途 | 设计 |
| --- | --- |
| 页面底色 | 暖白 #f7f8f2 |
| 正文 | 墨绿 #172822 |
| 辅助文字 | 灰绿 #465a51 |
| 链接与主要操作 | 深绿 #216451 |
| 分隔线 | 浅绿灰 #d1d9cc |
| 英文标题 | 衬线，随视口缩放 |
| 中文标题 | 系统宋体回退，独立处理字距 |
| 正文 | 无衬线，页面与图示共用一套基础字号 |
| 动作示意 | 深绿底，骨架、网格、轨迹与两帧残影。默认静止，用户主动播放 |
| 案例图 | 自绘概念图。CoMotion 用人体骨架，SandTouch 用沙纹，工程案例用模块连线 |

宽屏内容最大宽度 1200px。740px 以下首页与案例详情改为单列，490px 以下案例列表改为单列。导航可换行，语言入口保留在可见位置。键盘用户可跳到正文，焦点有可见描边。动效遵循系统减少动态效果偏好。

项目图和动作示意只表达设计概念。实际系统截图和演示视频应使用用户确认可公开的原始素材。

参考了 [Stanford HCI Group](https://hci.stanford.edu/) 的按会议组织论文方式，以及 [Bill Buxton 的个人主页](https://www.billbuxton.com/) 用具体作品引导读者继续探索的方式。
