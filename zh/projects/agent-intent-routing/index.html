智能体意图识别与 RAG 工作流

围绕意图识别、知识检索、多智能体路由与自动化评测构建的模块化智能体工作流。

项目概述

工作流接收用户请求、识别任务，并为负责处理的智能体准备所需上下文。意图识别、知识检索和路由是可单独评测的环节。

意图识别

我融合大模型少样本分类、向量相似度和关键词模式三路信号，通过加权决策输出结构化意图、实体和置信信号。证据较弱时，工作流会向用户澄清需求。

RAG 流程

工作流根据意图决定是否检索，将问题改写为语义互补的子查询，并行从 ChromaDB 召回相关内容。结果经过合并、去重和重排后，作为上下文传给智能体。

多智能体路由

路由模块根据结构化意图和提取的实体选择智能体，并传入相关上下文。意图置信度不足时，先澄清再路由。

动态技能

路由决定由哪个智能体处理请求，动态技能管理则决定该智能体在当前任务中可以使用哪些能力。

评测

我为意图分类和回复质量构建了评测流程。分类使用准确率和宏平均 F1，回复使用结构化评审，对照基线检查相关性、完整性和准确性。
