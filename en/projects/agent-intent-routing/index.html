Agent Intent Recognition & RAG Workflow

A modular agent workflow integrating intent recognition, knowledge retrieval, multi-agent routing, and automated evaluation.

Project Overview

The workflow takes a user request, identifies the task, and prepares the context needed by the agent handling it. Intent recognition, retrieval, and routing are separate steps, so each can be evaluated independently.

Intent Recognition

I combined signals from few-shot LLM classification, embedding similarity, and keyword patterns. A weighted decision returned a structured intent with entities and confidence signals, allowing the workflow to ask for clarification when the evidence was weak.

RAG Pipeline

An intent gate triggered retrieval only when useful. The workflow rewrote questions into complementary queries, retrieved in parallel from ChromaDB, and merged, deduplicated, and reranked the results before passing context to agents.

Multi-Agent Routing

The router uses the structured intent and extracted entities to select an agent and pass along the relevant context. Requests with weak intent signals go through clarification before routing.

Dynamic Skills

Routing determines which agent handles the request. Dynamic skill management determines which capabilities that agent can draw on for the current task.

Evaluation

I built checks for both intent classification and answer quality. Accuracy and macro-F1 tracked classification, while structured answer reviews made it possible to compare relevance, completeness, and correctness against a baseline.
