Go Microservice & Web Interface Development

A backend and web development practice covering Go microservice architecture, dependency injection, API integration, database and middleware integration, observability, and frontend interface development.

Project Overview

I worked on a migration to Go and Kratos and updated web interfaces that called the migrated services.

Frontend Development

I used HTML, CSS, and JavaScript to update the page structure, styling, and interactive behavior of management interfaces. I also connected and tested those interactions with the backend APIs.

Backend Architecture

The controller handled request and response adaptation, the business layer held rules, and the data layer owned persistence.

Dependency Injection

Wire made component dependencies explicit and assembled them when the service started.

API Integration

Protobuf described service contracts. The migration preserved existing HTTP calling patterns while I checked request and response compatibility and error propagation.

Database & Middleware

The migration integrated database access, Redis, and Kafka into the new service structure. I examined configuration initialization, message acknowledgement timing, and resource shutdown.

Observability

I traced how context passed between Gin middleware and the service framework and examined trace continuity across HTTP and database calls. The work connected service integration with logs, metrics, and OpenTelemetry traces.
