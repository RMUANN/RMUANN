Go Backend Services

Migration and integration work on layered Go services.

Service architecture

I worked on a migration to Go and Kratos. The controller handled request and response adaptation, the business layer held rules, and the data layer owned persistence. Protobuf described service contracts and Wire made construction dependencies explicit.

Integration and lifecycle

The migration preserved existing HTTP calling patterns and brought Redis and Kafka into the new service structure. I examined error propagation, acknowledgement timing, configuration initialization, and resource shutdown.

Observability

I traced how context passed between Gin middleware and the service framework and examined trace continuity across HTTP and database calls. The work connected service integration with logs, metrics, and OpenTelemetry traces.
